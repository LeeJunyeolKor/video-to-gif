VideoToGIF 설치 안내

이 파일은 팀 저장소의 공식 GitHub Release에서 받은 앱에만 사용하세요.

1. VideoToGIF.app을 실행합니다.
2. macOS가 앱을 열지 않는다는 경고를 표시하면 완료를 누릅니다.
3. 시스템 설정 > 개인정보 보호 및 보안의 보안 영역에서 확인 없이 열기를 누릅니다.
4. 암호 또는 Touch ID로 승인하고 열기를 누릅니다.
5. 응용 프로그램 폴더로 이동할지 묻는 창에서 이동을 누릅니다.
6. 첫 녹화를 시작할 때 화면 기록 권한을 허용합니다.

확인 없이 열기 버튼이 보이지 않으면 앱 실행을 다시 시도한 직후 개인정보 보호 및 보안 설정을 확인하세요.
